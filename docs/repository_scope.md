# Repository and evidence scope

ToyApollo keeps public source reviewable by separating reusable source from
mutable or source-derived evidence. Ignored files are preserved local state,
not deletion candidates.

## Classification

| Material | Public source plane | Private evidence plane | Reason |
| --- | --- | --- | --- |
| Python runtime, tests, tools | Yes | Optional snapshots | Required to inspect and develop the pipeline |
| Lean Task Parents and support Modules | Yes | Build snapshots | Central project output |
| Stable architecture and operator contracts | Yes | Historical drafts | Public Interface and current behavior |
| Full source-derived `inputs/` corpus | No | Yes | Copyright, provenance, and unnecessary public weight |
| Full `plans/` corpus | No | Yes | Derived from the private source corpus and mutable across ingestion work |
| Phase prompt packs | No | Yes | Generated, redundant, path-bearing working state |
| Batch queues, logs, reports, receipts | No | Yes | Execution evidence rather than reusable source |
| Operational `state.sqlite3` | No | Yes | Local mutable index that may contain workspace-specific state |
| Curated case-study exports | Yes | Full originals retained | Small, path-relative, immutable mechanism evidence |
| Historical one-off notes | No default navigation | Yes | Audit trail, not current runtime policy |
| Frozen external-source snapshots | No | Yes | Third-party provenance, not public runtime source |

## What a prompt pack is

A prompt pack is a task-scoped handoff directory generated by a pipeline phase.
A Phase 2 pack may contain:

- a mirror of the relevant source task;
- task and dependency metadata;
- the operator prompt and rendered review context;
- draft and numbered Lean candidates;
- build results;
- semantic-review requests, results, and reports;
- repair requests, diagnoser material, and attempt history;
- hashes and mutable pointers to the latest artifacts.

This is useful operational state, but it is a shallow public Module: its
Interface is nearly as large as its Implementation, it duplicates data, and it
often contains machine-local absolute paths. Public examples therefore export
the few facts needed to understand a case rather than track a live pack.

## What batch artifacts are

Batch artifacts describe a particular execution rather than the reusable
pipeline. They include scheduler plans, worker queues, dispatch state, status
snapshots, logs, summary reports, and transformation or apply receipts. They are
retained for diagnosis and provenance but do not decide semantic completion.

## What the large input corpus is

`inputs/` contains cleaned TeX source units derived from the local textbook;
`plans/` contains structured task decomposition derived from those units. The
pipeline can generate both for a user's own source, but ToyApollo does not need
to distribute the complete private corpus to expose its runtime and review
mechanism.

## Public case-study contract

A case study may enter `examples/case-studies/` only when it:

1. demonstrates a distinct mechanism or failure class;
2. uses path-relative, sanitized files;
3. includes only the minimum source description needed to understand the case;
4. records exact counts and hashes from retained evidence;
5. distinguishes observed facts from interpretation;
6. says explicitly that a selected case is not benchmark evidence;
7. compiles independently when it includes Lean snapshots.

The current selections are:

- `def_8_5`: build success, owner semantic failure, downstream migration
  failure, then a hash-bound pass;
- `def_10_1`: eight reviews, an older pass superseded by a stronger source
  check, and a recorded 40-target fanout inspection.

## Publication history rule

The existing private repository history has tracked source-derived material and
runtime evidence. Removing those files in a later commit does not remove them
from Git history. The first public release must therefore be produced as a
clean-history source snapshot after license, secret, path, and source-rights
checks. Do not make the research remote public in place.
